# ABIs exportados (VOTAR-385)

Full contract ABIs generated by `blockchain/scripts` (`npm run export:abis` / `deploy:sepolia:stack`).

```bash
cd ../blockchain && npm run export:abis
```

Archivos esperados: `MerkleRootStore.json`, `VoteRegistry.json`, `BallotContract.json`, `AuditViewContract.json`, `ElectionFactory.json`.

Las ABIs mínimas en `../constants/*.abi.ts` siguen siendo la superficie de runtime por defecto. Estos JSON son la fuente de verdad de la interfaz completa y alimentan `npm run validate:exported-abis` (UAT-04).
